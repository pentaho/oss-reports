Report formats

Both formats are generated from the same validated SBOM by the Pentaho security pipeline.

Machine-readable

CycloneDX JSON

A .zip archive containing a CycloneDX 1.6 JSON document with:

  • Complete component inventory with Package URLs
  • SPDX license identifiers with full license texts
  • License evidence and the concluded license per component
  • Snippet-scanned JavaScript libraries with copyright headers
  • SHA-256 hashes for integrity verification

Open it with the CycloneDX CLI, Dependency-Track or any JSON viewer.

Human-readable

PDF report

A printable rendering of the same SBOM, organised in two sections:

  • Components – every component with its package URL, version and license
  • Licenses – one section per license with its full text and the components it covers, including their copyright notices

Suited to legal review, procurement and attribution notices.

File naming convention

Files follow a predictable pattern so they can be published automatically from CI.

sbom-{build-name}-{version}.zip
sbom-{build-name}-{version}.pdf
build-name
The CI build identifier, for example pdi-openlineage-plugin-ee-main
version
The release version and build number, for example 0.7.0-292

Archive

Reports published before the CycloneDX format was adopted, retained for reference.
